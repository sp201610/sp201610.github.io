
# 西溪·水陆大会 亲子水基地设计方案
> 项目定位：西溪湿地北门生态区域改造，打造一座以自然河道和绿地为基底，聚焦亲子共玩、安全亲水、动手探索的湿地亲子基地。让家长带孩子安全地“湿身疯玩”或浅水接触，同时兼顾年轻家长自然场景拍照出片需求。

## 1. 前期调研
### 1.1 项目背景
拟对浙江杭州西溪湿地公园北门生态区域进行规划转型，改造为亲子活动基地。
- 区位优势：基地位于西溪湿地北门，紧邻地铁19号线，多条公交线路通达；北门配套停车场，小车5元/小时，单日封顶40元，自驾、公共交通双通道，亲子客流可达性强。

### 1.2 调研方法
- 定性访谈：31份半结构化深度访谈，面向0‑14岁儿童父母
- 问卷调查：96份有效问卷，覆盖用户偏好、需求、价值观、安全阈值等9个维度

### 1.3 调研目标
1. 验证“水陆大会”主题市场接受度
2. 明确目标用户画像、需求偏好、消费能力与安全阈值
3. 为产品定义、功能设计、运营策略提供量化依据

### 1.4 调研核心结果
#### 核心需求
优先级：**安全性＞教育性（问卷得分4.60）**
必备安全措施：救生员、护栏、水深标识警示、救生设备、浅水区、专人看护；家长具备基础户外安全认知（4.11分）

#### 用户痛点
|类别|痛点内容|
| ---- | ---- |
|场所问题|同质化严重、活动单一、人多拥挤、卫生差、商业化过重|
|水边顾虑|溺水落水风险（最高担忧，3.64分）|
|出行障碍|交通不便、孩子时间不足|
|配套短板|休息、餐饮、母婴配套设施不足|

#### 用户共识
1. 玩法：亲水轻体验（划船、捞鱼）接受度最高；排斥强刺激项目，偏好中等时长体验；纯观景需求低。
2. 客群：以学龄儿童家庭为主，家长是决策核心，家庭户外出行频次每月1‑2次。
3. 需求：安全第一，其次自然认知+动手能力教育，兼顾亲子互动，适配分龄需求。
4. 消费：价格接受度中等，愿意为高质量自然体验付费，孩子体验是首要决策因素。

## 2. 用户画像
### 2.1 用户聚类分析
|用户类型|占比|特征描述|
| ---- | ---- | ---- |
|理性型家庭|30%|核心付费群体；高度重视安全与教育价值；对产品品质要求高|
|务实型家庭|31%|有参与意愿，但受时间、交通、体力现实条件限制大；怕累、看重便捷|
|大众型家庭|38%|主流普通家庭；决策随意，高度依赖他人、社交平台推荐，容易踩雷|

### 2.2 典型人物Persona
#### 理性派｜梁爸爸
> 35岁，互联网产品经理，儿子9岁，家庭月收入3‑5万
- 行为：周末高频户外，爬山露营，深度参与亲子活动
- 痛点：厌倦商业化游乐场，希望玩乐同时获得教育价值
- 期待：安全保障到位，可划船捞鱼，锻炼孩子动手能力
- 社交：不热衷社交平台分享，以口头口碑传播为主
> 语录：玩就要玩真的，安全也要有保障。

#### 务实派｜王妈妈
> 32岁，银行职员，女儿5岁，家庭月收入2‑3万
- 行为：周末多选择商场乐园、社区公园；惧怕遛娃消耗大量精力
- 痛点：希望亲近自然，但出行怕远、怕走路劳累
- 期待：交通便利，少走路，孩子玩耍时家长可以休息
- 社交：参考妈妈群，决策重点评估性价比、体力成本
> 语录：带娃出门，大人不累才是真遛娃。

#### 大众派｜陈爸爸
> 36岁，普通职员，儿子7岁，家庭月收入2‑4万
- 行为：出行没有固定偏好，跟随朋友、小红书种草选择目的地
- 痛点：不知道去哪里玩，担心项目踩雷
- 期待：评价好，适合家庭结伴出行
- 社交：信息接收者，轻度传播
> 语录：有没有好玩又不用动脑子的地方？

### 2.3 核心需求对照
|维度|理性派|务实派|大众派|
| ---- | ---- | ---- | ---- |
|安全敏感度|极高|高|中高|
|玩法偏好|划船、捞鱼深度体验|浅水轻度活动|跟随大流|
|核心痛点|不安全、缺少教育价值|距离远、体力消耗大|怕踩雷体验差|
|社交传播意愿|低|中等|高|

## 3. 产品定义
> **项目slogan：西溪·水陆大会**
> 一座以自然河道和绿地为基底，聚焦亲子共玩、安全亲水、动手探索的湿地亲子基地。家长带孩子来的目的明确——让孩子安全地“湿身疯玩”或“浅水接触”，同时兼顾年轻家长在自然场景中拍照出片的需求。

### 3.1 5W1H
|维度|内容|
| ---- | ---- |
|Who|核心用户：理性家长(30%)、务实家庭(31%)；拓展用户：大众家庭(38%)；主要为杭州本地家庭，家庭月收入2‑5万|
|When|周末、节假日9:00‑18:00旺季；工作日10:00‑17:00淡季；夏季增设夜场18:00‑21:00|
|Where|西溪湿地北门，地铁19号线西溪湿地北E2出口；复用原生河道绿地，不新建大型建筑|
|What|皮划艇、捞鱼、浅水踩水、水乐园；家长休息区、换洗淋浴区；湿地自然探索科普|
|How|轻量可逆改造；搭建浮筒码头、安全围栏、标识系统；不硬化原有驳岸植被|
|Why|弥补市场同质化游乐产品缺口，依托西溪天然水系资源，打造安全自然向亲子亲水体验|

### 3.2 产品功能优先级
|P0（必做）|P1（强烈建议）|P2（建议）|P3（可选）|
| ---- | ---- | ---- | ---- |
|亲子皮划艇/桨板<br>岸边捞鱼区<br>完整安全设施体系|家长休息区<br>亲子换洗区|水乐园区|湿地自然探索角<br>水互动装置|

#### P0必做功能说明
1. **亲子皮划艇/桨板**：双人艇，家长陪同儿童；划定固定航线，浮球隔离边界，救生员值守。
2. **岸边捞鱼区**：缓坡入水，水深≤30cm；投放西溪原生鱼虾，提供网兜、观察小桶。
3. **安全设施体系**：救生员岗位、护栏≥1.1m、水深警示标识、救生物资、浅水区划分、水质公示。

#### P1强烈建议
1. **家长休息区**：遮阳座椅、充电、饮水点，可直接观察儿童活动，设置自然向打卡背景。
2. **亲子换洗区**：热水淋浴隔间、吹风机、更衣柜，地面防滑处理。

#### P2建议
水乐园区：浅水池、水枪、团队游戏，配套防水服、水鞋租赁。

#### P3可选
1. 湿地自然探索角：芦苇荡观鸟、植物认知牌，设置四季限定主题；
2. 水互动装置：手摇水车、引水渠互动模型。

### 3.3 安全设计规格
1. **划船水域**
    - 每1000㎡水域配置至少1名持证救生员；
    - 每条船只配备成人+儿童救生衣、头盔，未穿戴禁止下水；
    - 水域边界每5m设置安全浮球，夜场增设警示灯。
2. **捞鱼&戏水区**
    - 护栏高度≥1.1m；水深标识每5m布设；
    - 捞鱼区水深≤30cm；戏水池最大水深≤0.35m；
    - 池底铺设防滑软垫，摩擦系数≥0.8。

### 3.4 运营定价策略
> 原则：捞鱼、踩水、自然探索等基础项目包含在门票内，减少过多二次收费。

|票种|价格|适用人群|
| ---- | ---- | ---- |
|半日体验票（3h）|120元/家庭（两大一小）|不含皮划艇；适合体力敏感家庭|
|工作日特惠票|150元/家庭（两大一小）|工作日，面向祖辈、时间自由家庭|

**营销优惠**
1. 组团折扣：3组家庭9折，5组家庭85折，鼓励家庭结伴出行；
2. 淡季运营：对接幼儿园开展春秋研学（人均50‑80元）；工作日面向低龄儿童推出特惠；结合西溪四季推出限定主题活动。

## 4. 设计方案
### 4.1 总体布局：一核两翼、水陆双环，动静分区
#### 一核两翼
- **一核**：中心水域+浮屿，水上体验核心，浮球划分皮划艇活动边界。
- **东翼（湿身疯玩体验区）**：皮划艇码头、漂浮迷宫、水乐园、无动力戏水设施。面向理性派家庭，深度水上玩乐。
- **西翼（安全浅水+自然教育区）**：捞鱼踩水区、自然科普、水下玻璃栈道、家长休憩。面向务实、大众家庭，轻度亲水+自然教育。

#### 水陆双环动线
1. **主环路（体验闭环，1.5‑2h）**
`停车场→入口科普亭→入口更衣区→观景平台→浮屿码头→水乐园→亲子换洗区→捞鱼区→休憩亭→桥木→湿地自然探索区→水下庭院→入口区→离园评价领奖章`
2. **次级林间探索环（轻体验，40‑60min）**
`桥木入口→杉林栈道→植株科普点→互动科普设施群→水下玻璃栈道→水下庭院→观景平台→离园`

#### 动静分区
- 动区（东翼+核心水域）：皮划艇、漂浮迷宫、水乐园；
- 静区（西翼）：捞鱼踩水、植物科普、水下栈道、林间休憩；
- 过渡区：入口观景平台，安全宣教、换装准备。

> **湿干分流设计**：观景平台设置提示，家庭自由选择；湿身路线去往水上项目，结束后换洗；干身路线直接前往科普捞鱼区域，避免动线交叉。

### 4.2 关键设施节点
#### 浮屿｜水上枢纽
1. 皮划艇浮筒码头，可停靠6‑8艘双人艇；设置长短两条航行环线；
2. 下水安全教学区：每批次最多10人，救生员5分钟安全教学；安全可视化看板，公示救生员数量；
3. 模块化漂浮迷宫：200㎡可逆浮筒模块，非运营季可全部拆除；
4. 码头提供免费全家福拍摄，小程序获取电子照片。

#### 桥木｜自然文化入口
1. 木质科普指引牌，杉林栈道入口，植物科普二维码语音讲解；
2. 桥下观鱼平台，联动捞鱼挑战榜；
3. 四季活动预告牌：春探梅、夏赏荷、秋观柿、冬赏雪；
4. 小程序标记打卡点位，不设置实体装置。

#### 水岸｜浅水体验区
1. **捞鱼区**：架空木栈道，缓坡入水，水深≤30cm；高护栏、防滑池底；投放原生鱼虾，提供捞鱼工具；设置“放归小鱼”仪式；
2. **踩水区**：水深≤15cm鹅卵石浅滩，配套家长观察座椅；
3. 捞鱼挑战榜：公示当日特色渔获，放归小鱼家庭光荣榜；
4. 全域水深标识、水质公示、救生设备提示广播。

#### 观景平台 & 水下庭院｜配套枢纽
- **上层·观景平台**：家长遮阳休息区，充电饮水简餐；水质电子公示屏；全景打卡点。
- **下层·水下庭院**：临水茶座，提供茶饮家庭套餐；生态展板，生态瓶手作体验；水景灯带营造夜间氛围。

#### 休憩亭｜复合服务节点
1. 夏季临时水乐园，可拆卸池体；提供防水装备租赁；
2. 无动力戏水设施：单车喷泉、按压喷水器；
3. 急救箱、安全公示板，配置安全员；
4. 多季节复用：春秋野餐观景，冬季热饮观鸟。

#### 湿地自然探索区
1. **植株科普系统**：芦苇、柿树等本土植物解说台，标本盒、气味互动盒，二维码语音导览；
2. **下沉水下玻璃栈道**：长15‑20m三层夹胶玻璃，展示湿地水质治理科普；配置安全引导员；
3. **互动科普设施**：水车、迷你水坝、水循环沙盘，儿童可动手操作。

### 4.3 场地肌理控制
1. 尊重西溪塘基水陆破碎肌理，组团分散布置设施，不做大平整场地；
2. 高植被保护，沿原有林间步道布置科普点位，不砍伐原生植被；
3. 建筑密度极低；涉水设施全部桩基架空；配套使用集装箱、浮筒等可逆模块，运营结束可完全拆除复原，不破坏生态红线。

### 4.4 用户旅程与触点设计
完整旅程：`知晓→考虑→到达→入园→体验→离园→分享`

|旅程阶段|关键触点|设计机会点|
| ---- | ---- | ---- |
|知晓|小红书、妈妈社群|发布水下栈道、种子勋章种草内容|
|考虑|小程序、线上宣传|首页展示实时水质、在岗救生员数量|
|到达|地铁指引、停车场|脚印地贴，推车友好路线指引|
|入园|售票处、安全须知|把安全须知设计成儿童“小小安全员承诺书”|
|体验|浮屿码头、捞鱼区、水下栈道|下水前拍摄全家福；捞鱼放归仪式；湿地探索任务打卡|
|离园|换洗、纪念品柜台|完成评价，领取**种子勋章+育苗卡**|
|分享|朋友圈、小程序|晒发芽照片可换取免费入园，形成传播闭环|

### 4.5 线上触点
1. **公众号**：水质评级、项目介绍、实拍素材；
2. **小程序**：预约购票、组团拼团、入园码；实时水质公示；漫画版安全须知；湿地探索任务打卡；
3. **短信通知**：入园前天气装备提醒；离园回访；种子发芽提醒。

## 5. 评估反馈
### 5.1 分阶段测试计划
1. **阶段一 内测**：招募8‑10组家庭原型测试，收集操作成功率、满意度；
2. **阶段二 公测**：招募30‑50组家庭，模拟真实运营环境；
3. **阶段三 正式运营**：按月收集用户评价，按季度追踪满意度，迭代设施与服务。

### 5.2 评估维度与目标
|评估维度|评估方式|预期目标|
| ---- | ---- | ---- |
|安全性|安全事故统计、用户安全感知评分|零安全事故，安全感知≥4.5/5|
|易用性|任务完成率、求助次数|任务完成率≥90%，求助尽量少|
|满意度|系统可用性量表SUS、NPS净推荐|SUS≥70，NPS≥40|
|商业性|复购率、单客消费|3个月复购率≥20%，提升客单价|
|口碑|用户推荐意愿|80%用户愿意推荐亲友|

### 5.3 后续优化方向
1. 玩法迭代：结合季节开发萤火虫观察等限定活动；
2. 动线容量：高峰动态调整排队动线，扩充休息区；
3. 会员体系：开发会员，开设湿地自然小课堂；
4. 场景拓展：开发夏季夜场、夜游观虫等特色项目。
